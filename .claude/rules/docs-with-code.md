If this change alters behavior an editor or admin page could describe (a screen, a command, a
default, an error, what an action commits, writes, or refuses), load the `cairn-writing-docs` skill
and follow its case A to the end, including the fresh `docs-fact-checker` run. A change to a public
export, option, or type also updates its doc comment and the packaged skill reference under
`skills/` that teaches it. A fix with no API change can still make a page false. Before you decide
no page changes, search `docs/editors/`, `docs/admin/`, and `skills/` for the action's name and for
what it writes, read every hit outside history, and show the command in your reply.
