# Set up and run a cairn site

This track is for the person who sets up and runs a cairn site: comfortable pasting a command into a terminal, clicking through a dashboard, and following written steps exactly, but not a developer. You write no code here. The setup command, `create-cairn-site`, does the work, and these pages explain what it does, state what it costs, and get you moving again when a step stops.

If you write content on a site that someone else set up, you want the editors' help instead, which opens from the admin's **Help** link. If you build custom screens or features on cairn, you want the [extend track](../extend/README.md).

## Pick the page that fits

The following table routes you by what is happening now.

## The pages, in order

1. [Before you start](./before-you-start.md) covers what you end up owning, what it costs, and what a developer still has to do.
2. [Create your site](./create-your-site.md) takes you from nothing to a live site with you signed in.
3. [Own your domain](./own-your-domain.md) moves the site onto a domain you own, turns on sign-in email, and connects automatic deploys.
4. [Invite editors](./invite-editors.md) adds the people who will write on the site.
5. [Check that your site works](./is-it-working.md) explains each result of the readiness check.
6. [Recover a setup that stopped](./setup-recovery.md) gets a failed or interrupted setup moving again.
7. [Troubleshoot a live site](./troubleshooting.md) finds the fix for a site that does the wrong thing, or finds out who can.

Two more documents belong with this track. [Credentials](./credentials.md) says which secrets the `cairn` command stores and where. [The tripwire](./tripwire.md) describes the guard that stops a development stand-in from running on a live site.
