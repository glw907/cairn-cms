# Help for editors

This is help for the editor you write in: the screen where you draft, save, and publish
entries for your site. If you came from the **Get help** link inside the editor, you're in
the right place.

## Where to start

- **[Welcome](./welcome.md)**—what this editor is, and how to sign in.
- **[Write in the editor](./write-in-the-editor.md)**—everything about writing and
  formatting a draft: the toolbar, links, images, and keyboard shortcuts.
- **[Publish and history](./publish-and-history.md)**—move an entry between private and
  live, and get an earlier version back if you need to.
- **[When something goes wrong](./when-something-goes-wrong.md)**—the editor refused
  something, or a message appeared that you don't understand. Start here first if you're
  stuck.

## Other things you might need to do

- **[Add an image](./add-an-image.md)**—put a picture in the draft you're writing.
- **[Manage the media library](./manage-the-media-library.md)**—work on your site's
  stored images without a draft open.
- **[Manage your tag list](./manage-your-tag-vocabulary.md)**—keep the shared list of
  tags every editor picks from.
