# Add an image

You can put a picture into the draft you're writing in three ways: upload a new one, reuse one the site already has, or set the lead picture that goes with the whole entry. This page shows each way, including how to name an image and how to describe it for readers who can't see it.

You need a draft open in the editor. The page doesn't cover the file types the admin accepts or the size limit, and it doesn't cover working on images outside a draft. For those, see [Manage the media library](manage-the-media-library.md). For writing the draft itself, see [Write in the editor](write-in-the-editor.md).

## Insert an image into the text

Start by opening the **Insert image** panel.

1. Put the cursor where you want the picture.
1. Select **Insert image** in the toolbar. It's the button with a small picture on it.

The panel opens next to your cursor.

You can also skip the panel. When you paste an image or drag an image file into the draft, the editor opens the upload form directly.

## Reuse an image the site already has

Reuse an image when the picture is already in the media library. You don't upload it again.

1. In the **Insert image** panel, select the box labeled **Search the media library**.
1. Type part of the image's name or its alt text. The list narrows as you type.
1. Select the image you want. The editor inserts it at your cursor and closes the panel.

A reused image brings along the alt text saved with it in the library. A row marked **Needs alt** has none yet. If the list says **No images in the library yet.**, the site has no images to reuse. Use the upload steps in the next section.

## Upload a new image

1. In the **Insert image** panel, select **Upload an image**.
1. Choose the file in the window that opens. The upload form appears with a small preview of your picture.
1. In the **Name** field, type a name you'd recognize later. The library lists the image under this name. The field starts with the file's name and a **Suggested** mark. A name from a camera or screenshot tool, such as IMG_4821, gets no suggestion, so the field starts empty.
1. Under **Alt text**, select **Write a description** and type a short description, or select **Mark as decorative**.
1. Select **Insert image**.

The picture appears in your draft right away while it uploads, and the editor swaps in the finished image when the upload completes. Save the draft as usual to keep it.

### Choose between a description and decorative

Alt text is a short description of a picture. Screen readers read it aloud to people who can't see the picture. Say what the picture shows, as you would to someone on the phone.

- Select **Write a description** for a picture that carries meaning, such as a photo of the trailhead.
- Select **Mark as decorative** for a picture that adds nothing to the words around it, such as a divider or an ornament. Screen readers skip it.

You can insert a picture without choosing either one. The editor then warns you about pictures that have no alt text, but the warning never stops you from saving. The editor doesn't remember a decorative choice for a picture in the text, so it can still list that picture as needing alt text after you reload the draft.

## Set the lead picture

The lead picture is the one image that leads the page. It's also the picture shown when someone shares the entry on social media. Its field sits in the **Details** panel, and your site names it, so the label may differ from **Lead picture**.

1. Open the **Details** panel.
1. In the lead picture field, select **Add** followed by the field's name, such as **Add lead picture**.
1. Drop an image into the window, or select **Choose a file**. To reuse an image instead, search under **or pick from the library**.
1. Check the preview. Then select **Describe it** and type a short description, or select **Decorative**. The **Caption** box is optional.
1. Select **Use this image**.
1. Select **Save** so the entry keeps the picture.
