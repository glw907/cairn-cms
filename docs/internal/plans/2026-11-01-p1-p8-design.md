## Decisions

1. **The no-binding route.** The refusal, `resolveDb` returning undefined, builds now. What waits is an
   action with `resolveDb` omitted, since the option turns optional in pass 3 (E4). It is set aside to
   pass 3 and filed at close.
2. **`Secure`, no prefix.** `buildCookieName` gives `__Host-`, which needs `Path=/`, and these cookies
   are deliberately path-scoped to `/admin`. A `__Secure-` prefix would change the name on `https`
   only, with every reader and about 20 e2e cookie seeds following, for a theme preference.
3. **Charset and trailing slash stay doc lines.** XML declares its own encoding, a robots file is
   ASCII, and JSON is UTF-8 by rule, so no harm is measured. #156 in `## Won't do` took the same line.
   `html_handling` would edit `wrangler.*`, an `auth-data` path, for a redirect status with no reader.
4. **`messageId` logging set aside.** It needs a log field in `auth-routes.ts`, an `auth-data` path
   with one security read coming in pass 7. Filed there at close.
5. **GitHub failure strings set aside.** `src/lib/github/**` is on the `auth-data` map, and those 13
   lines already name the operation and status. Touching them would cost this pass a security read and
   a live smoke. Filed for pass 7 at close, with the `defineRoles` strings in `src/lib/auth/roles.ts`.
6. **`env.ts` strings left to pass 3.** They throw `CairnError`, whose remediation ergonomics 16
   appends, so a next step written here would print twice.
7. **The generic `Not found` strings stay.** The inventory's row proposed "go back to the dashboard",
   and the admin has no dashboard. A 404 that says nothing more refuses nothing an editor can act on.
8. **`ownerOnly` stays on unit tests.** The e2e dev handle mints an owner, so no spec can reach that
   refusal; `signups/actions.test.ts` and `section-action.test.ts` hold it.
9. **The prerender rule is `advisory`.** A public route may choose per-request rendering, and an
   explicit `false` satisfies the rule. `Tier` says a compositional rule starts `advisory` "until
   measured evidence promotes it".
