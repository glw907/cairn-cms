## The pre-release workaround, recorded (and one defect found by it)

The scaffold's engine spec `^0.94.0` resolves on the registry to a version that does not
export `previewLoad`/`PreviewBanner` (the T5a finding), and `@glw907/cairn-cms-dev` has
never published, so the honest tarball cannot build against the registry. The workaround
extends `create-site.yml`'s `file:` rewrite so the Builds machine can install it too:
both tarballs are vendored INTO the site at `vendor/` and the specs rewritten to
relative paths (`file:vendor/glw907-cairn-cms-0.94.0.tgz`,
`file:vendor/glw907-cairn-cms-dev-0.0.0.tgz`), committed and pushed with the site.
`pushScaffold` uploads blobs base64-encoded, so the binary tarballs survive the API
push. This disappears at release one, when the registry serves the window.

Rehearsed before the sitting (the discipline that split T5): `npm install` then
`npm run build` in the rewritten scaffold, build exit 0.

**Defect: a tarball-installed scaffold has no `.gitignore`.** npm excludes `.gitignore`
from every tarball, `scaffold.mjs` is a plain recursive `cp` of the packed template, and
nothing regenerates the file. Proven live: the scaffolded site carried `.gitattributes`
but not `.gitignore`. The exposure is the one `repo.mjs`'s own comment names:
`collectFiles` hardcodes only `node_modules`/`.git`/the sentinel, and relies on the
site's `.gitignore` for `.svelte-kit/`, `.wrangler/`, `dist/`, and `.dev.vars`. The
scaffold's own hand-over text tells the user to `npm install && npm run dev` before the
GitHub chapter, so the natural path puts build output and local secret material in the
tree the push walks. Every prior e2e ran from the checkout (where `template/.gitignore`
exists), and `create-site.yml` asserts nothing about it, which is how it stayed
invisible. **Run intervention, recorded:** the baked `.gitignore` was restored into the
scaffold before the GitHub chapter and the rehearsal's `.svelte-kit/`/`.wrangler/`
deleted, so this known defect does not contaminate every downstream hop's evidence. Fix
belongs to the pass close, with a packed-tarball-path test.
