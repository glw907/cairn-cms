The switch

Two things make today's switch odd. The tight ladder squared off its knob, so it looks like a checkbox sliding inside a box. And when it's on, only the knob changes: the track stays white, so the state reads only by position.

B and C treat the switch as round. That's the same exemption as the avatar and the dirty-state dot: a switch is a physical metaphor, and it means round. C also fills the track with the ink when on, the convention every OS switch uses, so on and off read at a glance. The fill is the ink, not violet, which keeps the accent reservation. Click one.
