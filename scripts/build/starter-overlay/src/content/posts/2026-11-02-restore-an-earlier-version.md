---
title: Restore an earlier version
date: 2026-11-02
description: Bring back a version of a post or page you published before.
author: author
---
Each time you publish, the editor keeps that version. If a change turns out to be a mistake, you can bring the earlier text back.

1. Open the post or page.
2. Select **More actions**, and then select **History**.
3. In the **Recent versions** list, find the version you want, and select **Restore as draft** on its row.
4. Read the text on the editing screen. The editor saved the old version as a draft, and your site still shows the current version.
5. Select **Publish** to make the old version live. To drop it, select **Discard changes** from the **More actions** menu.

If the entry already has a saved draft, the editor won't restore until you publish or discard that draft. The list shows the 25 most recent published versions.
