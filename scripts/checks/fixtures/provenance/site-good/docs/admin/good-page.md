# Check a site

This page walks through one check.
Run `cairn doctor --json` in your site directory. It exits 0 when every check passes.

The defaults are floors, not ceilings.

- A GitHub installation token expires after one hour.
- See the [pricing page](https://example.com/pricing) for Workers Paid.

```sh
cairn doctor --json
```

| Command | What it does |
| --- | --- |
| `npm run check:facts` | Walks every fact. |

`defineConcept` declares a concept, and the [logger guide](../extend/logging.md) covers the rest.
