# The cairn-hero-lead class

The recessed sub-line inside a hero.

Rendered markup:

```html
<p class="cairn-hero-lead">A lead sentence.</p>
```

Reads:

- The measure `--container-measure`, the size `--text-step-1`, the leading `--leading-snug`, and the color `--color-muted`.

Override seams:

- Override the color with `--color-muted`, which also moves every other secondary line.
