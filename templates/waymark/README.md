# cairn Waymark template (generated, pre-release)

This directory is generated by [cairn-cms](https://github.com/glw907/cairn-cms)'s
`emit-template-dir` script from the `examples/showcase` starter. Do not edit any file here
directly: every emit regenerates the whole tree, a hand edit survives at most one run, and
`npm run check:template` fails the build when the committed tree and a fresh bake disagree.

It lives at `templates/waymark/` rather than in a repository of its own because Cloudflare's
Deploy button and C3's `--template` both accept a subdirectory. Cloudflare treats that
subdirectory as the root of the repository it creates for a user, and requires the application be
fully isolated within it, which is why this directory sits outside the root `package.json`'s
`packages/*` workspace glob: a workspace member has no lockfile of its own.

This template is pre-release. The Deploy button, the completion checklist, and the rest of
this file's user-facing content land once the button flow has been verified live.
