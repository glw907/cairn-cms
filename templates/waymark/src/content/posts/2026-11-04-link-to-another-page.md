The editor has two kinds of link. A web link goes to another website. A link to a page goes to another entry on your site, and it keeps working if you later change that entry's address.

To link to a page or post on your site, follow these steps:

1. Place the cursor where the link should go, or select the words that should carry it.
2. In the toolbar, select **Link to page**.
3. In the **Link to a page** dialog, search by title, and then select the entry.

You can also type `[[` followed by a few letters of the title. Choose a match from the list and the editor inserts the link.

To link to another website, select **Web link**, type the address in the **Web address** box, and select **Add link**.

The editor won't save a link to an entry that doesn't exist or has never been published. It lists each broken link so you can remove it.
