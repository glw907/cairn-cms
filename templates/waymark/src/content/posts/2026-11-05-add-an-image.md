Pictures break up a long post, and a description makes them usable for everyone. You add both in one panel.

To upload a picture and place it in your text, follow these steps:

1. Open the post and place the cursor where the picture should go.
2. In the toolbar, select **Insert image**.
3. In the panel, select **Upload image**, and then choose the file.
4. In the **Name** box, type a name you'll recognize later.
5. Under **Alt text**, select **Write a description**, and type a short description of what the picture shows. If the picture is decoration only, select **Mark as decorative**.
6. Select **Insert image**.

Alt text is the description a screen reader reads aloud. Describe what the picture shows and why it's there, and leave out opening words such as "image of."

To use a picture you've already uploaded, select **Insert image**, search the media library, and choose it. It brings its description along.
